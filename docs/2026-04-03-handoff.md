# 2026-04-03 Handoff

## Context

このリポジトリは、一般的なコーヒー推薦デモから、GIS レビュー担当者向けの自由が丘限定 PoC に再定義された。

現在の PoC 定義は次の通り。

- 対象は東京・自由が丘
- 対象カテゴリはコーヒーショップとコーヒー豆店
- 地図表示は MapLibre で行う
- 推薦の MVP はキュレーション済みデータ + 明示的な空間ルールベースで行う
- 一般的な LLM を最終意思決定に使わない
- 出力は単一ベストではなく Top 3 を許容する
- 必要なら後続で絞り込み質問を追加する

## What Was Decided

### Product direction

- これは単なるカフェ検索ではなく、GIS 根拠付き推薦 PoC として扱う
- 想定閲覧者は GIS に詳しい社内レビュー担当者
- 外部 GeoAI や推薦 API を前提にしない
- 外部 API 制約に左右されにくい実装経路を採る

### Implementation direction

- 地図は可視化とレビュー文脈の提示に使う
- 推薦の MVP は、自由が丘限定のキュレーション済み候補に対して、距離、カテゴリ、範囲制約などの明示的ルールでランキングする
- 地図可視化と、ローカル計算によるランキングは UI 上で区別して見せる
- 既存の東京全域デモ文脈は捨てる

### Data operation rule

- 店舗データの単一ソースは `src/data/coffee  map - coffee-map-spots.csv`
- 説明文は `description`、理由文は `semantic_reasons` を編集する
- `src/data/mockPlaces.ts` は CSV 読み込み専用レイヤーとして扱い、データ本体の手編集はしない

### Spec Kit setup

Spec Kit はこのリポジトリに初期化済み。

主な参照先:

- `.specify/memory/constitution.md`
- `specs/001-geoai-jiyugaoka/spec.md`
- `specs/001-geoai-jiyugaoka/plan.md`
- `specs/001-geoai-jiyugaoka/tasks.md`

現在の feature branch:

- `001-geoai-jiyugaoka`

## Current Implementation Target

今後の実装対象は次の 3 点。

1. 地図を使った GIS 可視化
2. 自由が丘限定の地理制約
3. 明示的な空間ルールベース推薦

この組み合わせを、PoC として最も安全に「GIS 根拠付き推薦」と説明する。
