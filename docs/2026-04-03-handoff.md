# 2026-04-03 Handoff

## Context

このリポジトリは、一般的なコーヒー推薦デモから、GIS レビュー担当者向けの自由が丘限定 PoC に再定義された。

現在の PoC 定義は次の通り。

- 対象は東京・自由が丘
- 対象カテゴリはコーヒーショップとコーヒー豆店
- ArcGIS は地図表示と GIS レビュー文脈の中心に置く
- 推薦の MVP はキュレーション済みデータ + 明示的な空間ルールベースで行う
- 一般的な LLM を最終意思決定に使わない
- 出力は単一ベストではなく Top 3 を許容する
- 必要なら後続で絞り込み質問を追加する

## What Was Decided

### Product direction

- これは単なるカフェ検索ではなく、GIS 根拠付き推薦 PoC として扱う
- 想定閲覧者は GIS に詳しい社内レビュー担当者
- ArcGIS GeoAI を強く主張しすぎない
- ArcGIS Personal Use 制約を前提に、無理のない実装経路を採る

### Implementation direction

- ArcGIS は主に地図表示と GIS 文脈の提示に使う
- 推薦の MVP は、自由が丘限定のキュレーション済み候補に対して、距離、カテゴリ、範囲制約などの明示的ルールでランキングする
- ArcGIS ベースの可視化と、ローカル計算によるランキングは UI 上で区別して見せる
- 既存の東京全域デモ文脈は捨てる

## ArcGIS Account Findings

### Important constraint

ArcGIS Personal Use では、API キー前提の実装や GeoAI/API 利用がそのまま成立しない可能性が高い。

このため、現時点では次の前提に置き換えている。

- API キーがあっても、ライブ推薦エンジンの前提にはしない
- ArcGIS は地図と可視化の中心に残す
- 推薦ロジックはローカルに説明可能な形で構成する

### Current interpretation

現時点の実務的な整理は以下。

- ArcGIS GeoAI を前面に出したライブ推薦: リスクが高い
- ArcGIS 可視化 + GIS ルールベース推薦: 現実的
- 一般的な LLM に判断させる構成: 不採用

## Current Implementation Target

今後の実装対象は次の 3 点。

1. ArcGIS を使った GIS 可視化
2. 自由が丘限定の地理制約
3. 明示的な空間ルールベース推薦

この組み合わせを、PoC として最も安全に「GIS 根拠付き推薦」と説明する。
