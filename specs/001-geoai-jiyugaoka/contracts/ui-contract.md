# UI 契約: 自由が丘 GIS根拠付きコーヒー推薦 PoC

## 入力契約

### 意図検索フォーム

- **入力項目**: 自由記述の日本語テキストエリア
- **必須**: はい
- **挙動**:
  - 雰囲気、目的、コーヒーの好み、店舗イメージに関する自然言語を受け付ける
  - 入力変更または明示的な再計算操作のあとに推薦を更新する

## 出力契約

### 推薦サマリーパネル

- **必須表示項目**:
  - 現在の検索エリア名: 自由が丘
  - 現在の推薦モード: GIS ルールベース推薦、または同等の明示的なモード名
  - 結果件数: 最大 3 件
  - 解釈された意図タグまたは解釈メモ

### 推薦カード

各カードに含めるもの:

- 店舗名
- 店舗カテゴリ
- 住所
- スコアまたは順位
- 短い説明
- 空間的な理由
- レビュー担当者向けの理由一覧
- ソースまたはモード表示

### 地図パネル

- 自由が丘を中心に表示すること
- 表示中の推薦候補点をすべて載せること
- 地図上から推薦候補を選択できること
- 選択中の候補が視覚的に分かること

### 詳細パネル

選択中の候補について以下を表示する:

- 店舗名
- カテゴリ
- 住所
- 説明文
- 理由の箇条書き
- ソースまたはモード表示

## エラー状態・制約表示

- ランキングが外部 AI のライブ出力であるかのように見せてはならない
- スコープとカテゴリで絞った結果、妥当な候補が残らない場合は、作り物の推薦ではなく制約説明を表示しなければならない
- 一般的な AI の自信や根拠不明の確信を UI に出してはならない
