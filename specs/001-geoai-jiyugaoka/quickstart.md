# クイックスタート: 自由が丘 ArcGIS GIS根拠付きコーヒー推薦 PoC

## 目的

このアプリが、一般的な東京カフェデモや LLM 依存の推薦モックではなく、自由が丘限定で ArcGIS を中核に据えた GIS レビュー向け PoC として振る舞うことを確認する。

## セットアップ

1. `npm install` を実行する
2. 必要なら `.env.example` を `.env` にコピーする
3. `VITE_ARCGIS_API_KEY` がある場合は、地図または参照レイヤー用途に限って設定する
4. `npm run dev` を実行する

## 手動確認シナリオ

### シナリオ1: 自由が丘に限定された推薦

1. アプリを開く
2. 現在の対象エリア表示が自由が丘になっていることを確認する
3. `静かで豆もちゃんとしている店に行きたい` と入力する
4. UI 上の推薦結果が最大 3 件であることを確認する
5. すべての推薦が自由が丘内にあり、コーヒーショップまたは豆店であることを確認する

### シナリオ2: GIS レビュー可能な説明

1. 各推薦カードを選択する
2. 詳細表示に以下が含まれていることを確認する
   - 現在のモードまたはデータソース
   - 店舗カテゴリ
   - 空間的な理由
   - ArcGIS または対象範囲に関係する説明が少なくとも 1 つあること

### シナリオ3: ランキング根拠の明確化

1. `VITE_ARCGIS_API_KEY` の有無にかかわらず実行する
2. ランキングが、キュレーションデータと GIS ルールによるローカル計算なのかどうかを UI が明示していることを確認する
3. 推薦が、利用できない ArcGIS GeoAI や一般的な LLM 判断から来ているかのような文言になっていないことを確認する

### シナリオ4: 自然言語の揺れへの対応

1. `雰囲気いいロースターに行きたい` を試す
2. `朝に入りやすくて作業もできる店` を試す
3. どちらも対象範囲内の妥当な結果が返ることを確認する

## 受け入れチェックリスト

- アプリが自由が丘だけを対象にしている
- 結果がコーヒー関連カテゴリに限定されている
- 既定出力が Top 3 以下である
- ArcGIS の使い方とランキング根拠が見える
- 推薦理由を GIS レビュー担当者が追える
